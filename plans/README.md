# Plans

Design docs and implementation plans for GrooveTracker. One file per feature or milestone.

## Convention

- Name files `NNN-short-slug.md`, e.g. `001-project-scaffolding.md`. Numbers are sequential
  and never reused.
- Use `TEMPLATE.md` as the starting structure.
- Plans are written by the `planner` agent (`/plan-feature <description>`), reviewed by you,
  then broken into entries in `tasks/TASKS.md`.
- A plan is a living document until its work is done — update it if the approach changes,
  then note the change.
